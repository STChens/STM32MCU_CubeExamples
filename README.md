# OEM-uROT for Nucleo-N657X0-Q board
This branch provides oem-urot examples for Nucleo-N657X0-Q
The example is made basing on STM32N6 CubeFW package v1.1.0 + v1.1.1 patch 

OEMuROT_BOOT and OEMuROT_Appli folders includes the OEMuROT example for Nucleo-N657X0-Q board. 
The projects are modified basing on the OEMuROT example for STM32N6570-DK board. 

To use the files from this branch, you need to get the base package of STM32N6 CubeFW from st.com
